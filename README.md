# Background

# Contents
## 1) Speedrun Categorisation:
This is a pair of graphics that map out speedrun categories for doom. The graphics were created using an open-source tool [draw.io](https://app.diagrams.net/) and the native file is included in the respective folder as well as an exported jpeg images of each diagram.
Note: the diagrams represents the minimum requirements to be assigned to a set speedrun category.

The relevant files are stored in the associated folder, namely:
+ [Speedrun_Categorisation.drawio](/Speedrun_Categorisation/Speedrun_Categorisation.drawio) -> Native file for draw.io, to enable editing and updates
+ [Speedrun_Categorisation_VennDiagram.jpg](/Speedrun_Categorisation/Speedrun_Categorisation_VennDiagram.jpg) -> Jpeg export of current venn diagram
+ [Speedrun_Categorisation_FlowDiagram.jpg](/Speedrun_Categorisation/Speedrun_Categorisation_FlowDiagram.jpg) -> Jpeg export of current flow diagram

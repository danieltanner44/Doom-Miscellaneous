# Contents
## 1) Speedrun Categorisation:
This is a graphic that maps out speedrun categories for doom. The graphic was created using an open-source tool [draw.io](https://app.diagrams.net/) and the native file is included in the respective folder as well as an exported jpeg image.
Note: the diagram represents the minimum requirements to be assigned to a set speedrun category.

The relevant files are stored in the associated folder, namely:
+ [Speedrun_Categorisation_Venn-Diagram.drawio](/Speedrun_Categorisation/Speedrun_Categorisation_Venn-Diagram.drawio) -> Native file for draw.io, to enable editing and updates
+ [Speedrun_Categorisation_Venn-Diagram.jpg](/Speedrun_Categorisation/Speedrun_Categorisation_Venn-Diagram.jpg) -> Jpeg export of current diagram
